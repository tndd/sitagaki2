# ドメイン構成

## dataset
- 未加工の完全な生データセット

## feature
データセットから加工や結合を行い、特徴量エンジニアリングを施したデータ。

## model
定義される要件
- 特徴量
- 目的変数
- モデル

グルーピングはモデルごとに行う

**Think**
- [x] [モデルの受け取るデータの型は？](docs/qa/モデルの受け取るデータ型.md)
> pldfで受けて、train&validに変換


## strategy
- modelの計算結果を元に取引戦略を決定する
- 戦略ごとにバックテストを行い、その計算結果が保存されるイメージ

## trade
- strategyの戦略を実際の取引行動に落とし込む
