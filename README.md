# ドメイン構成

## dataset
- 未加工の完全な生データセット

## feature
データセットから加工や結合を行い、特徴量エンジニアリングを施したデータ。

**Think**
- [x] [データの変形機能の所属は？](docs/qa/データの変形機能の所属.md) -> pldf


## model
定義される要件
- 特徴量
- 目的変数
- モデル

グルーピングはモデルごとに行う

**Think:**
モデルの受け取るデータの型は？
無難な受け取り方はtrain & validだが、あまり下書き段階で受け方を複雑化させたくない。
単体のPLDFを受け取って、それを元にモデルを作るというふうにしたい。

## strategy
- modelの計算結果を元に取引戦略を決定する
- 戦略ごとにバックテストを行い、その計算結果が保存されるイメージ

## trade
- strategyの戦略を実際の取引行動に落とし込む
