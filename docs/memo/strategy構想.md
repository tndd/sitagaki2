# strategyの要件
コンセプトとしてはモデルを評価することにある。
さらにいえば、モデルの予測値を元にした取引戦略を評価する。
モデルの評価だけならば、それはmodel内で行われるべきところだ。

だったらこのstrategyが受け取る引数とはどうなるか？

# strategyの引数
model
これは複数受け取り得るな。
プロトタイプでは、簡略化のため単一のモデルを受け取ることになるだろう。

df
モデルが評価するためのデータは確実に必要だ。
今のところ、dfとモデルの関連性を明示する構造がない。
dfから見たら、どのモデルから処理されるかは知ったことではない。
むしろモデルの方がどのdfを対象にしているかという依存を持ってる。

# strategyの出力
まず何の項目を出力とするかを決めないといけない。
