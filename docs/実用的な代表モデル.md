### **各分野での最新・実用的な代表モデル**

**大きく分けて以下の系統がある**：

1. **時系列・シーケンスデータ** → Transformer / LSTM / GRU
2. **決定木・ブースティング系** → LightGBM / XGBoost
3. **画像処理** → CNN / Vision Transformer (ViT)
4. **テキスト・自然言語処理** → GPT / BERT 系
5. **グラフデータ** → GNN（Graph Neural Network）
6. **強化学習・ゲームAI** → DQN / PPO / AlphaZero 系
7. **異常検知・異常検出** → Isolation Forest / Autoencoder 系
8. **マルチモーダル（画像+テキスト）** → CLIP / Flamingo / GPT-4V

---

## **1. 時系列・シーケンスデータ**

| モデル | 特徴 | 主な用途 |
| --- | --- | --- |
| **Transformer** | 並列処理可能、長期依存関係を学習 | 自然言語処理・時系列解析・動画解析 |
| **LSTM** | 長期依存が強い、逐次処理 | 時系列予測・医療データ解析・スポーツ分析 |
| **GRU** | LSTM の軽量版、短期依存に強い | 音声認識・リアルタイム予測 |
| **TCN (Temporal Convolutional Network)** | 1D CNN ベースの時系列処理 | 時系列データ、異常検知 |

🔥 **最新・実用モデル**:

- **TimeSformer**（動画解析用 Transformer）
- **Informer**（ロングシーケンスの時系列予測）

---

## **2. 決定木・ブースティング系**

| モデル | 特徴 | 主な用途 |
| --- | --- | --- |
| **LightGBM** | 計算効率が良い、カテゴリ変数に強い | 金融・マーケティング |
| **XGBoost** | 勾配ブースティングで高精度 | 金融・不正検知 |
| **CatBoost** | カテゴリデータに強い | Eコマース・広告分析 |
| **Random Forest** | 汎用性が高い | 一般的な分類・回帰 |

🔥 **最新・実用モデル**:

- **TabNet**（深層学習ベースのテーブルデータ解析）
- **NGBoost**（ニューラルネット×決定木）

---

## **3. 画像処理**

| モデル | 特徴 | 主な用途 |
| --- | --- | --- |
| **CNN（ResNet, EfficientNet）** | 画像認識の標準モデル | 医療画像解析・スポーツ解析 |
| **Vision Transformer (ViT)** | 画像をパッチで処理する | 画像認識・生成AI |
| **Swin Transformer** | ViT の改良版、高解像度画像に強い | 高精度画像処理 |
| **YOLO (You Only Look Once)** | 高速物体検出 | 自動運転・監視カメラ |

🔥 **最新・実用モデル**:

- **Swin Transformer V2**（高精度画像認識）
