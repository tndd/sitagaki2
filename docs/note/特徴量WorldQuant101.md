# Worldquant 101アルファ特徴量の詳細解説

以下は、Worldquantの"101 Formulaic Alphas"で紹介されている具体的なアルファ因子の詳細解説です。これらはクオンツトレーディングで使用される数学的公式で、市場の非効率性を捉えることを目的としています。

基本用語解説;
- **rank(x)**: 値をランク付け（大きい順に順位付け）する関数
- **correlation(x, y, d)**: xとyのd期間の相関係数
- **ts_rank(x, d)**: 過去d期間におけるxの時系列ランク
- **delta(x, d)**: 現在のxと過去d期間前のxとの差
- **sum(x, d)**: 過去d期間のxの合計
- **delay(x, d)**: d期間前のxの値
- **ts_min(x, d)**: 過去d期間におけるxの最小値
- **ts_max(x, d)**: 過去d期間におけるxの最大値
- **adv20**: 過去20日間の平均出来高
- **returns**: 日次リターン
- **stddev(x, d)**: 過去d期間におけるxの標準偏差
- **vwap**: 出来高加重平均価格

# 個別アルファ因子の解説

## Alpha#1
```
(rank(Ts_ArgMax(SignedPower(((returns < 0) ? stddev(returns, 20) : close), 2.), 5)) - 0.5)
```

**解釈**: 
- リターンが負の場合は20日間のリターンの標準偏差を使用し、そうでない場合は終値を使用
- それを2乗し、過去5日間で最大値を取った日のランクから0.5を引いた値

**振る舞い**: 
このアルファは市場のボラティリティとモメンタムの関係を捉えようとします。リターンが負の時にはボラティリティに、正の時には価格そのものに注目します。このアルファが高い値を示す銘柄は、直近でボラティリティが増加している（下落時）か、または価格が上昇傾向にある可能性が高いです。

## Alpha#2
```
(-1 * correlation(rank(delta(log(volume), 2)), rank(((close - open) / open)), 6))
```

**解釈**: 
- 出来高の対数の2日間の変化のランクと、日中リターン（終値-始値）/始値のランクとの6日間の相関係数に-1を掛けた値

**振る舞い**:
このアルファは出来高の変化と日中のリターンの関係性に着目しています。出来高の増加とリターンの変化が逆相関の時（出来高増加時に日中リターンが下落する場合）に高い値を示します。これは、通常の「出来高が増えると価格も上がる」という関係に反する状況を捉え、市場の異常を検出しようとしています。

## Alpha#3
```
(-1 * correlation(rank(open), rank(volume), 10))
```

**解釈**:
- 始値のランクと出来高のランクとの10日間の相関係数に-1を掛けた値

**振る舞い**:
始値と出来高の逆相関を捉えようとします。始値が高い時に出来高が少ない（または始値が低い時に出来高が多い）銘柄に正の値を与えます。これは価格と出来高の不一致から生じる市場の非効率性を利用しようとするものです。

## Alpha#4
```
(-1 * Ts_Rank(rank(low), 9))
```

**解釈**:
- 安値のランクの9日間の時系列ランクに-1を掛けた値

**振る舞い**:
直近9日間で安値のランクが低下傾向にある銘柄（つまり、相対的に安値が上昇している銘柄）に高い値を与えます。これは下値の堅さを示すシグナルとして機能し、上昇トレンドの可能性がある銘柄を識別します。

## Alpha#5
```
(rank((open - (sum(vwap, 10) / 10)))) * (-1 * abs(rank((close - vwap))))
```

**解釈**:
- (始値 - 過去10日間のVWAPの平均)のランクと、(終値 - VWAP)のランクの絶対値に-1を掛けた値との積

**振る舞い**:
このアルファは始値と過去のVWAPの乖離、および当日の終値とVWAPの乖離の関係を捉えています。始値が過去のVWAP平均から大きく乖離し、かつ終値がVWAPに近い銘柄を識別します。これは価格が平均に回帰する傾向を利用した戦略です。

## Alpha#6
```
(-1 * correlation(open, volume, 10))
```

**解釈**:
- 始値と出来高の10日間の相関係数に-1を掛けた値

**振る舞い**:
始値と出来高が逆相関を示す銘柄を識別します。始値が上昇するときに出来高が減少する（または始値が下落するときに出来高が増加する）パターンを持つ銘柄に高い値を与えます。これは価格と出来高の間の通常の関係からの乖離を表し、価格の反転を示唆する可能性があります。

## Alpha#7
```
((adv20 < volume) ? ((-1 * ts_rank(abs(delta(close, 7)), 60)) * sign(delta(close, 7))) : (-1 * 1))
```

**解釈**:
- 当日の出来高が過去20日間の平均出来高より大きい場合、7日間の終値の変化の絶対値の60日間の時系列ランクに-1を掛け、7日間の終値の変化の符号を掛ける
- それ以外の場合は-1を返す

**振る舞い**:
出来高が急増している銘柄に着目し、その中で過去7日間の価格変化の方向と大きさを考慮します。出来高の急増と価格の大きな変動が結びついている銘柄を識別するための因子です。

## Alpha#8
```
(-1 * rank(((sum(open, 5) * sum(returns, 5)) - delay((sum(open, 5) * sum(returns, 5)), 10))))
```

**解釈**:
- (過去5日間の始値の合計 * 過去5日間のリターンの合計)と、それを10日前にずらした値との差のランクに-1を掛けた値

**振る舞い**:
過去5日間における始値の総和とリターンの総和の積の変化を捉えます。これは、始値とリターンの関係性の変化を捉え、直近の市場の状態と10日前の市場の状態を比較することで、モメンタムの強さの変化を測定します。

## Alpha#9
```
((0 < ts_min(delta(close, 1), 5)) ? delta(close, 1) : ((ts_max(delta(close, 1), 5) < 0) ? delta(close, 1) : (-1 * delta(close, 1))))
```

**解釈**:
- 過去5日間の終値の1日変化の最小値が0より大きい場合（一貫して上昇）、当日の終値の変化を返す
- 過去5日間の終値の1日変化の最大値が0より小さい場合（一貫して下落）、当日の終値の変化を返す
- それ以外の場合は当日の終値の変化に-1を掛けた値を返す

**振る舞い**:
このアルファは、一貫したトレンドを識別し、そのトレンドの継続を予測します。過去5日間で一貫して上昇または下落している銘柄については、そのトレンドが継続すると予測し、それ以外の場合は反転を予測します。これはトレンドフォロー戦略とリバーサル戦略を組み合わせたものです。

## Alpha#10
```
(rank(((0 < ts_min(delta(close, 1), 4)) ? delta(close, 1) : ((ts_max(delta(close, 1), 4) < 0) ? delta(close, 1) : (-1 * delta(close, 1))))))
```

**解釈**:
- 過去4日間の終値の1日変化の最小値が0より大きい場合（一貫して上昇）、当日の終値の変化を使用
- 過去4日間の終値の1日変化の最大値が0より小さい場合（一貫して下落）、当日の終値の変化を使用
- それ以外の場合は当日の終値の変化に-1を掛けた値を使用
- 最終的にその値のランクを取る

**振る舞い**:
Alpha#9の変種で、最終的な値にランク付けを行います。このアルファはトレンドの一貫性と反転のシグナルを組み合わせています。過去4日間で価格が一貫して上昇または下落している場合、そのトレンドの継続を予測し、それ以外の場合は反転を予測します。

## Alpha#11
```
((rank(ts_max((vwap - close), 3)) + rank(ts_min((vwap - close), 3))) * rank(delta(volume, 3)))
```

**解釈**:
- 過去3日間の(VWAP - 終値)の最大値のランクと最小値のランクの和に、過去3日間の出来高変化のランクを掛けた値

**振る舞い**:
このアルファは、価格（VWAP vs 終値）の乖離と出来高の変化の関係を捉えています。VWAPと終値の乖離が大きく、かつ出来高が増加している銘柄を識別します。これは、価格が大きく動き、それに伴って取引が活発化している状況を捉えようとする因子です。

## Alpha#12
```
(sign(delta(volume, 1)) * (-1 * delta(close, 1)))
```

**解釈**:
- 出来高の1日変化の符号に、終値の1日変化に-1を掛けた値を掛けた結果

**振る舞い**:
出来高の変化と価格の変化の関係を捉えます。出来高が増加した場合に価格が下落する、または出来高が減少した場合に価格が上昇するという非直感的な状況に高い値を与えます。これは市場の効率性の低下を示唆するシグナルとして機能します。

## Alpha#13
```

```

**解釈**:
- 終値のランクと出来高のランクの5日間の共分散のランクに-1を掛けた値

**振る舞い**:
終値のランクと出来高のランクの間の共分散が小さい（または負の）銘柄に高い値を与えます。共分散が低いということは、終値と出来高の関係が弱いか逆の関係を持つことを意味し、これは市場の非効率性を示唆する可能性があります。

## Alpha#14
```
((-1 * rank(delta(returns, 3))) * correlation(open, volume, 10))
```

**解釈**:
- リターンの3日間の変化のランクに-1を掛けた値と、始値と出来高の10日間の相関係数との積

**振る舞い**:
リターンの動きと、始値と出来高の関係の組み合わせを捉えます。リターンが減少している（または増加幅が縮小している）銘柄の中で、始値と出来高が正の相関を持つ銘柄、あるいはリターンが増加している（または減少幅が縮小している）銘柄の中で、始値と出来高が負の相関を持つ銘柄に高い値を与えます。

## Worldquant 101アルファ特徴量のまとめ

Worldquantの101アルファは、株式市場における様々な価格パターンと取引動向を捉えるために設計された数学的な因子（特徴量）の集合です。これらのアルファは以下のような特徴を持っています：

1. **多様な時間枠**：短期（数日）から長期（数百日）までの様々な時間枠を考慮しています。

2. **複数の価格指標**：始値、高値、安値、終値、VWAP（出来高加重平均価格）など、複数の価格指標を組み合わせています。

3. **産業・セクター中立化**：多くのアルファは産業やセクター内での相対的な動きを捉えるために中立化処理を行っています。

4. **複合的な関係**：価格と出来高の関係、異なる時間枠間の関係、ランク間の関係など、複雑な相互作用を捉えています。

5. **統計的手法**：相関、ランク付け、線形減衰、時系列ランクなど、様々な統計的手法を活用しています。

6. **非線形変換**：多くのアルファでは、べき乗、対数変換、条件分岐などの非線形変換を適用しています。

これらのアルファ因子は、単独でも予測力を持つ可能性がありますが、多くの場合、複数のアルファを組み合わせることで、より強固で安定した投資戦略を構築することができます。また、これらのアルファはあくまで過去のデータに基づいて設計されているため、市場環境の変化によっては有効性が変わる可能性があることに注意が必要です。

実際の運用においては、これらのアルファを市場環境や投資目標に合わせて適切に選択・調整し、さらにリスク管理やポートフォリオ構築の手法と組み合わせることが重要です。
